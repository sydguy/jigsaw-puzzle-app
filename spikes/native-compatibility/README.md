# M1 compatibility harness

This is a local technical proof, not production gameplay or approved UI. Native gates are still blocked on owner accounts/identifiers and physical validation.

From this directory on Windows:

```powershell
../../tools/with-node.ps1 npm.cmd run web
```

The helper selects the already-installed bundled Node runtime when available. It does not change the system installation. With a supported system Node, `npm run web` or `npx expo start --web` works normally.

The harness renders 384 synthetic jigsaw paths with Skia. It must not be used to claim native performance, production picture availability, verified subscriptions or ad completion.
