# Navigation assets

Created 5 October 2026 with the built-in image-generation tool, using design/mobile/mobile-homev1.png as a style reference. Existing imported graphics were not changed.

- navigation_home.png: rounded filled house, peaked roof, doorway cutout.
- navigation_collection.png: four rounded squares in a two-by-two grid.
- navigation_settings.png: eight-tooth gear with a circular center hole.

Prompt for each asset: create one isolated mobile bottom navigation icon matching the corresponding symbol in the reference; single purple #5430E8, transparent background, no text, frame, shadow or extra elements; centered square composition readable at 28px. Subject descriptions above were supplied separately. Built-in generation was used, not the CLI.

The original generated PNGs retain transparency. Components use contain sizing and tint for selected/unselected states. Native tabs use template rendering on iOS; the operating system controls their final layout. No generated artwork is a production catalogue picture.
